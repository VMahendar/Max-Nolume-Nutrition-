# PR #1 conflict resolution

The merge retains main's premium navy, royal blue and silver storefront, all five Unicorn Pro Series products, variant-specific customer prices, persistent cart, product details, search/sorting and WhatsApp availability checkout. Main's payment/delivery suspension is preserved; this merge does not activate integrations. The existing server checkout, payment verification, order history, inventory, administration and staging protections remain in place.

The separate dealer page retains its WhatsApp business enquiry form and adds authenticated business access. Customers register/sign in through account.html and apply for gym or wholesale access. An administrator reviews applications in admin.html. Only approved accounts can fetch /api/dealer/catalog. Private prices are rendered for that account without localStorage persistence and cleared when the page is hidden or left. Public storefront prices remain retail even for a signed-in dealer. Missing approved trade prices display a private quotation request, never an invented discount.

Authentication still uses server-side scrypt password hashes and hashed HttpOnly cookie sessions. Static assets contain no real wholesale prices or authentication secrets. API responses and pages are served with no-store. The Node service serves only public/; GitHub Pages also publishes only public/. Static Pages can show the retail catalogue and enquiries, but secure accounts and dealer pricing require the Node backend on the same origin.

Validation: npm run check and all 40 automated tests pass, including a new HTTP test covering anonymous/pending dealer denial, approved private prices, retail separation and logout. Existing tests cover pricing, signed payment verification, order ownership, inventory, administration, staging and backups. Chromium checks passed for catalogue/variants, product details, search, cart quantities/totals/persistence, checkout enquiry URL, registration, application, approval, private pricing, logout and dealer enquiry at 320, 390, 768 and 1440px. No page JavaScript errors were observed. External manufacturer images were deliberately failed in the browser test to check fallbacks; third-party image availability and actual WhatsApp delivery are not asserted. Payments/courier calls were mocked in automated tests; no live payment, shipment or message was sent.
