ONE SHIPPING PROVIDER

Shiprocket & courier pickup

Set up one seller account and collect shipments from your real packing location. Use Delhivery when available for an actual route.

Create free Shiprocket seller account ↗

Checking connection…

  1. Register as a seller. Open the official Shiprocket website, select Seller, register Max Volume Nutrition and personally verify the mobile OTP. Signup is not completed inside this website.
  2. Complete business KYC. Use the legal business identity and settlement details in Shiprocket's secure portal. Do not upload credentials or bank documents to GitHub.
  3. Add a pickup address. In Shiprocket go to Settings → Pickup Address → Add New Pickup Address. Register the actual premises where packed parcels will be handed to the courier—not a non-trading virtual office.
  4. Create a dedicated API user. In Shiprocket go to Settings → API → Add New API User; assign only the required shipping modules. Store API credentials in Render environment settings, never in source code.
  5. Verify serviceability and wallet. Confirm collection from your pickup PIN, eligible couriers, package weights, recharge requirements and charges before a real booking.

After connection: schedule a pickup

Open Online orders, select a verified paid order, create its Shiprocket shipment, assign the offered courier/AWB and run Schedule pickup. Generate the label/manifest and hand the parcel to the driver when the courier confirms collection.

Pickup requests, shipping costs, WhatsApp notifications and customer checkout remain disabled in staging. No delivery is promised merely because an outlet is nearby.

Production launch checklist

Owner-only, read-only verification of the existing Render website. A green check requires actual provider credentials, a confirmed business identity and real acceptance tests. Do not toggle payments or couriers based only on a preview.

Checking current readiness…

Required before switching to production: verified merchant and settlement bank account in Razorpay, valid GST billing identity, usable Shiprocket pickup address and API user, full product photos and stock checks, custom domain, backups and recovery testing. Do not send secret keys or bank account credentials through chat; store provider keys only in Render encrypted environment settings.

Existing test orders must not be passed off as real customer records. The deployment can remain accessible in preview while this checklist is incomplete.
